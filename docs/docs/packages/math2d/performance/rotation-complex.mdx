# Rotation & Complex Performance

Performance analysis for `Rotation2` and `Complex` — transcendental function costs,
normalization overhead, and rotation composition throughput.

<RotationPerformance />

## Key Characteristics

- **Transcendental operations** (`sin`, `cos`, `atan2`) use fdlibm kernels for determinism,
  which adds a constant overhead vs native `Math.*`
- **`*CS` variants** accept pre-computed `(cos, sin)` to avoid redundant trig calls in loops
- **Normalization** is required after composition to prevent drift in the (cos, sin) representation

For measurement methodology, see [Methodology](../../../performance/methodology).
