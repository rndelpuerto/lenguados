# Interval & Transform Performance

Performance analysis for `Interval` (1D ranges with set operations) and `Transform2`
(Scale-Rotate-Translate compositions).

<IntervalTransformPerformance />

## Key Characteristics

- **Interval set operations** (`union`, `intersect`, `contains`) are branch-heavy due to
  min/max comparisons but operate on only 2 floats
- **Transform2 composition** decomposes into Scale, Rotate, Translate steps — the `multiply`
  operation is the hot path in scene graph traversal
- **Transform2 inverse** requires computing the inverse of the rotation and negating the
  scaled translation

For measurement methodology, see [Methodology](../../../performance/methodology).
