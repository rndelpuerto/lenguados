# Getting Started

**Lenguados** is a deterministic, extensible 2D physics engine built in TypeScript. It is organized as a monorepo of independent packages -- install only the packages you need.

## Available Packages

| Package                                               | Description                                                        | Install                           |
| ----------------------------------------------------- | ------------------------------------------------------------------ | --------------------------------- |
| [`@lenguados/math2d`](./packages/math2d/overview)     | Core 2D math primitives (vectors, matrices, rotations, transforms) | `npm install @lenguados/math2d`   |
| [`@lenguados/common`](./packages/common/overview)     | Shared utilities for cross-cutting concerns                        | `npm install @lenguados/common`   |
| [`@lenguados/examples`](./packages/examples/overview) | Interactive demos and visual tests                                 | `npm install @lenguados/examples` |
