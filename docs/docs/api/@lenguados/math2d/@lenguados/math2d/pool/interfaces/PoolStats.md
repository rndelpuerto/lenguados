# Interface: PoolStats

Statistics about pool usage.

## Properties

### available

> **available**: `number`

Number of objects available in the pool

---

### inUse

> **inUse**: `number`

Number of objects currently in use

---

### maxSize

> **maxSize**: `number`

Maximum pool size

---

### total

> **total**: `number`

Total number of objects created

---

### utilizationRate

> **utilizationRate**: `number`

Percentage of created objects currently in use
