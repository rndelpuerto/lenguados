# Function: fract()

> **fract**(`value`): `number`

Gets fractional part.

## Parameters

### value

`number`

Value to get fraction from

## Returns

`number`

Fractional part (always positive)

## Example

```typescript
fract(3.7); // 0.7
fract(3.2); // 0.2
fract(-3.7); // 0.3
fract(-3.2); // 0.8
fract(5); // 0
```
