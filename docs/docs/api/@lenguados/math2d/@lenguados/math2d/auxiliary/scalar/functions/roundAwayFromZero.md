# Function: roundAwayFromZero()

> **roundAwayFromZero**(`value`): `number`

Rounds to nearest integer away from zero.

## Parameters

### value

`number`

Value to round

## Returns

`number`

Rounded value

## Example

```typescript
roundAwayFromZero(1.5); // 2
roundAwayFromZero(-1.5); // -2
roundAwayFromZero(1.4); // 1
roundAwayFromZero(-1.4); // -1
```
