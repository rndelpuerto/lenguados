# Function: truncatedMod()

> **truncatedMod**(`dividend`, `divisor`): `number`

Truncated modulo (same as %).
Included for completeness and clarity.

## Parameters

### dividend

`number`

Value to divide

### divisor

`number`

Divisor

## Returns

`number`

Truncated remainder

## Example

```typescript
truncatedMod(7, 3); // 1
truncatedMod(-7, 3); // -1
truncatedMod(7, -3); // 1
truncatedMod(-7, -3); // -1
```
