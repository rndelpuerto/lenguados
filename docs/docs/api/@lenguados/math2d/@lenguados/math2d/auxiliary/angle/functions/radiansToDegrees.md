# Function: radiansToDegrees()

> **radiansToDegrees**(`radians`): `number`

Converts radians to degrees.

## Parameters

### radians

`number`

Angle in radians

## Returns

`number`

Angle in degrees

## Example

```typescript
radiansToDegrees(Math.PI); // 180
radiansToDegrees(Math.PI / 2); // 90
radiansToDegrees(2 * Math.PI); // 360
```
