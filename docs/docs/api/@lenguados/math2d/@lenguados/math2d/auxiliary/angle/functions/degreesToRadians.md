# Function: degreesToRadians()

> **degreesToRadians**(`degrees`): `number`

Converts degrees to radians.

## Parameters

### degrees

`number`

Angle in degrees

## Returns

`number`

Angle in radians

## Example

```typescript
degreesToRadians(180); // Math.PI
degreesToRadians(90); // Math.PI / 2
degreesToRadians(360); // 2 * Math.PI
```
