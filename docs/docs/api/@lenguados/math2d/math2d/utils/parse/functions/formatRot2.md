# Function: formatRot2()

> **formatRot2**(`r`, `format`, `precision?`): `string`

Formats a 2D rotation as a string.

## Parameters

### r

[`ReadonlyRotation2`](../../../../@lenguados/math2d/core/type-aliases/ReadonlyRotation2.md)

Rotation to format

### format

Output format: 'radians', 'degrees', 'components', 'json'

`"json"` | `"radians"` | `"degrees"` | `"components"`

### precision?

`number`

Number of decimal places

## Returns

`string`

Formatted string
