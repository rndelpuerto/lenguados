# Function: formatMat3()

[`ReadonlyMatrix3`](../../../../@lenguados/math2d/core/type-aliases/ReadonlyMatrix3.md)

### format

Output format

### precision?

`number`

Number of decimal places

## Returns

`string`

Formatted string
